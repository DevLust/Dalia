# Dália Ateliê de Noivas

Sistema de gestão (React + Vite + TypeScript). Dados em `localStorage`.

## Executar

```bash
npm install
npm run dev
```

Abra `http://localhost:5173`.

**Login de teste:** `admin@dalia.com.br` / `admin123`

**Build:** `npm run build` — saída em `dist/`.
